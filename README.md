# Portfolio

My personal portfolio website, showing who I am, my skills and the projects I have built as a junior web developer.

## Live Demo

[https://alabitobiloba.github.io/Portfolio/](https://alabitobiloba.github.io/Portfolio/)

## What's on the Site

- **About:** how I started programming on my phone, and the skills I have built
- **Projects:** a calculator, a to-do list, two C++ lab exercises (School Fees Calculator and NEB Electricity Billing System), and this portfolio itself
- **Contact:** a button to email me

## Features

- Dark theme with an orange accent colour
- Layout that adapts to phone and desktop screens
- Mobile menu that opens and closes with a menu button
- Hover effects on buttons, skill tags and project cards

## Built With

- HTML
- CSS
- JavaScript (for the mobile menu)

## How It Works

The page is built with HTML sections (About, Projects and Contact). CSS handles the colours, spacing and layout, including the changes for smaller screens. A short JavaScript script toggles the menu on phones: it adds or removes a class on the menu button and navigation, and closes the menu when a link is tapped.
